# NEON 记账 · 赛博账本

一个赛博朋克风格的本地记账 Web App（PWA）。手机浏览器打开即可用，可「添加到主屏幕」像 App 一样全屏使用，数据保存在本机浏览器，无需服务器。

## 功能

- 手动记一笔：金额、分类（餐饮/交通/购物/娱乐/居住/医疗/其他）、账户（微信/支付宝/银行卡/现金/其他）、备注、时间
- 今日 / 本月 / 全部 三种视图切换
- 分类占比环形图 + 近 7 日支出趋势柱状图
- 导入微信 / 支付宝导出的账单 CSV（自动识别表头、收支方向、分类与账户）
- 导出 / 导入 JSON 备份
- 载入示例数据（方便预览界面效果）
- 赛博朋克交互界面：霓虹发光、故障字效、扫描线、粒子背景、动态图表

## 如何运行

方式一（最简单）：直接用浏览器打开 `index.html`。

方式二（推荐，启用 PWA 离线安装，需本地起个静态服务器）：

```bash
# Python
python -m http.server 8000
# 或 Node
npx serve .
```

然后手机和电脑在同一 Wi-Fi 下，用手机浏览器访问 `http://<电脑IP>:8000`，点浏览器菜单「添加到主屏幕」。

## 如何导入账单

1. 微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单（用于个人对账），解压得到 CSV。
2. 支付宝：我的 → 账单 → 右上角 … → 开具交易流水证明 / 下载账单，解压得到 CSV。
3. App 内点右上角 ⚙ →「导入账单 CSV / JSON」，选择文件即可。

> 说明：微信 / 支付宝不向个人开放账单 API，因此目前无法全自动同步，需手动记一笔或导入官方导出的账单文件。银行卡账单同样可导出 CSV 导入（兼容常见银行格式）。

## 数据与隐私

- 所有数据只保存在当前浏览器 localStorage 中，不会上传到任何服务器。
- 换手机或清理浏览器前，请先在 ⚙ 里「导出备份 JSON」。

## 文件结构

- `index.html` 页面结构
- `styles.css` 赛博朋克样式
- `app.js` 业务逻辑（记账、统计、导入导出）
- `charts.js` Canvas 图表（环形图、柱状图）
- `manifest.json` / `sw.js` / `icon.*` PWA 安装支持
